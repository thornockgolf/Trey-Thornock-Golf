# Integrations

Env var **names** only; values live in `.env` (gitignored, local) and Coolify (production). Template: `.env.example`. Declared for SvelteKit in `apps/app/src/env.ts` and `apps/marketing/src/env.ts`.

| Integration | Used by | Env vars | Notes |
|---|---|---|---|
| **Clerk** (hosted) | `apps/app` | `PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, `COACH_CLERK_USER_IDS` | `svelte-clerk` 1.2.0 (unofficial, peers on Kit 2 but runs on Kit 3). Dev instance locally; production instance later. Marketing loads no Clerk. Account deletion calls the Backend API (`clerkClient.users.deleteUser`, via `ClerkAdmin`; a 404 counts as done). Name and email sync: on a request where the row has never been synced or the last sync is over a day old, `currentUser` reads the user from the Backend API (`ClerkAdmin.getProfile`, 2 s timeout) and stores the name and primary email (`Users.syncProfile`). Best effort: a failure is logged, the request goes on, and that process backs off for a minute. A name the player typed on their profile is kept; a missing value never blanks a stored one. Not yet run against the real Clerk instance. |
| **Postgres** (Supabase image) | app, worker | `DATABASE_URL` | Local: `docker compose up -d db` (`supabase/postgres:15.8.1.085`, host port 54322, matches the VPS). `app` schema for tables, `pgboss` for the queue. Migrations: `bun run db:migrate`. |
| **Cloudflare R2** (S3 API) | app, worker | `R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET` | One private bucket; key layout `raw/ processed/ analysis/ profile/` from `keys.*` in `@ttg/shared`. Presigned PUT/multipart 15 min, GET 1 h. CORS set for `localhost:5173/5174` and `app.treythornockgolf.com` (GET, PUT, POST, HEAD; `ETag` exposed). SDK checksums disabled (`WHEN_REQUIRED`). The worker has its own `Storage` service (streamed download, multipart upload via `@aws-sdk/lib-storage`, and a delete limited to `analysis/` keys for the retention sweep). Verified against the real bucket for presigned PUT (a wrong Content-Type is rejected), multipart with resume, HEAD, attachment GET, and the worker pipeline. The Cloudflare API token is not used by the app. |
| **Stripe** | `apps/app` | `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_ASSESSMENT`, `STRIPE_PRICE_MEMBERSHIP`, `PUBLIC_STRIPE_PUBLISHABLE_KEY` (unused: Checkout is hosted) | `stripe` 23.0.0, test mode. Checkout (assessment `payment`, membership `subscription`) and the Customer Portal are created by the app; `POST /webhooks/stripe` (public, signature over the raw body, verified with `constructEventAsync` because the sync check fails under Bun) is the only writer of payment state, once per event id. Verified against the test account: both products and prices exist, a real test-card assessment and membership, a Portal session, and the resulting events replayed through the handler (current API shapes: period end on the subscription item, `invoice.parent.subscription_details`). Not verified: Stripe delivering to a registered endpoint, `invoice.payment_failed` from Stripe. Prices live in Stripe; the billing page copy says $149 and $49 a month. Account deletion calls `customers.del` (cancels subscriptions; a missing customer counts as done); only exercised against a stand-in. |
| **Web push** | app, worker | `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (all optional) | `web-push` 3.x in `packages/db`. See `jobs-and-realtime.md`. Not delivered to a real device. |
| **Supabase Realtime** | app, worker | `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_JWT_SECRET` (all optional) | `@supabase/realtime-js` 2.117.3 in the browser. See `jobs-and-realtime.md`. Not run against a real server. |
| **Netlify** | marketing | `PUBLIC_APP_URL`, `PUBLIC_SHOW_APP_LINKS` (build-time) | `apps/marketing/netlify.toml`. Live site still deploys the original HTML from `main`; not relinked yet. |
| **Coolify** (Hostinger VPS) | app, worker | see `docs/deploy.md` | Not deployed yet; Dockerfiles tested locally. |
| **app server** | adapter-node | `ORIGIN` (production), `PORT` (default 3000), `HOST` | |
